# Shadow · UI 设计规格

> 跟读录屏工具的 Ghost UI 设计规范。配套视觉参考见 `ui_design/preview/`（用浏览器打开，含可交互演示）。
> 目标实现：现有 `shadow_recorder.py`（PyQt6），改造 `ScreenWindow` / `CameraWindow` / `SubtitleCard`。

---

## 0. 设计哲学（Ghost UI）

工具应**近乎隐形**，让用户几乎无感知。除必要操作按钮外，其余 UI 与文字尽量弱化或去掉。

- **白色为主**，深色磨砂玻璃为底，不用刺眼色块
- 弱化一切线条与块状图形；能用"内容本身"界定的，就不加边框
- 用户只感知两件事：**屏幕内容本身** + **需要时出现的操作按钮**

---

## 1. 整体架构

竖屏跟读：**上半录浏览器视频，下半录用户摄像头**，合成抖音/小红书竖屏视频。

两个独立的 frameless 置顶透明窗口（现有架构已是这样）：

| 窗口 | 类 | 作用 |
|------|-----|------|
| 录屏区 | `ScreenWindow` | 透明挖空，框住浏览器视频区域 |
| 摄像头区 | `CameraWindow` | 显示用户本人画面 |
| 字幕 | `SubtitleCard` | 字幕浮层 |
| **雾遮罩（新增）** | `FogOverlay` | 录制中非录制区雾化（见 §6） |

两窗口可**各自独立拖拽**到桌面任意位置，也可上下贴合使用。

## 2. 配色 / 材质 Token

| Token | 值 | 用途 |
|-------|-----|------|
| 录制区线框（待定） | `rgba(255,255,255,0.5)` 1px | 录制前白线框 |
| 区内分界线 | `rgba(255,255,255,0.28)` 1px | 录屏区/摄像头区之间 |
| 雾·贴边峰值 | `rgba(255,255,255,0.16~0.17)` | 录制中非录制区，贴录制区边缘 |
| 雾·向外渐变 | → `rgba(255,255,255,0)` | 约 50px 范围渐淡消失 |
| 主按钮 | `bg rgba(255,255,255,0.90)` / `text #111` | 开始录制、保存 |
| 次按钮 | `bg rgba(15,15,15,0.5)` + `border rgba(255,255,255,0.28)` / `text 0.92` | 停止、取消、重录 |
| 录制红点 | `#FF3B30` | 录制指示，1.2s 呼吸 |
| 状态文字 | `rgba(255,255,255,0.4~0.7)` | 尺寸标 / 计时 |
| 摄像头暖色底 | `linear 上(70,55,45)→下(24,19,15)` | 房间暖光感 |

按钮统一 `backdrop-filter: blur(12px)`（PyQt6 用半透明 + 圆角近似）。

## 3. 状态机

```
收起(capsule) ──展开──> 待机 ──开始录制──> 倒计时(3s) ──> 录制中 ──停止──> 完成 ──保存/重录──> 待机
```

| 状态 | 录屏区 | 摄像头区 | 雾遮罩 |
|------|--------|---------|--------|
| **收起** | 胶囊（见 §7） | 隐藏 | 无 |
| **待机** | 白线框 + 尺寸标 + 字幕icon | 白线框 + 画面 + [开始录制] | 无 |
| **倒计时** | 白线框 + 大数字 3/2/1 | 大数字 + [取消] | 无 |
| **录制中** | 线框消失 + 红点计时 | 线框消失 + [停止] | **出现**（非录制区雾化）|
| **完成** | 白线框 + "已录制 m:ss" | 白线框 + [重录][保存视频] | 无 |

## 4. 录屏区（ScreenWindow）改造

去掉现有的**顶栏黑条 TOPBAR** 和**蓝/红实心边框**，改为：

- **录制前**：仅一圈白线框 `rgba(255,255,255,0.5)` 1px（`paintEvent` 画 `drawRect`），无顶栏、无四角加粗
- **录制中**：白线框**不画**（靠雾遮罩界定边界）
- **区内左上角**：状态标 —— 待机显示 `WIN_W × content_h`（白 0.4）；录制中显示 `● 00:32`（红点 + 计时，白 0.7）
- **区内右上角**：字幕 icon（见 §8），取代现有顶栏的字幕/语言按钮
- **底部拖拽调高**：保留现有 HANDLE 逻辑（拖动改 `content_h`）；视觉简化为底部中央一个小横把手 `rgba(255,255,255,0.55)`，hover 变亮
- 录屏区只框**纯视频**，不含浏览器标题栏

> 现有 `paintEvent`（行 646）整体重写：去 TOPBAR `fillRect`、去蓝红 `drawRect`+四角，按上表重画。

## 5. 摄像头区（CameraWindow）改造

- **录制前/完成**：白线框 `rgba(255,255,255,0.5)` 1px
- **录制中**：线框不画（靠雾界定）
- **操作按钮浮在摄像头区底部内侧居中**（`bottom:12px`，磨砂玻璃，避免挡脸）：
  - 待机 → `[● 开始录制]`（主按钮）
  - 倒计时 → `[取消]`（次按钮）
  - 录制中 → `[■ 停止]`（次按钮）
  - 完成 → `[重录]`（次）+ `[保存视频]`（主）

## 6. ★ 录制前后视觉 + 雾化实现（核心）

### 视觉目标
- **录制前**：白线框示意"录制待定区"，桌面完整可见
- **录制中**：白线框消失 → **非录制区**雾化（淡白，贴录制区边缘向外渐变消失，**不遮全屏，远处完全漏出画面**），录制区内清晰
- **停止**：雾化消失，恢复白线框
- **多录制区**：每个录制区各自雾化跟随；**两区重叠/相邻部分不雾化**（都是录制区，保持清晰）

### PyQt6 实现策略：新增 `FogOverlay(QWidget)`

```python
# 一个覆盖全屏的透明置顶遮罩，鼠标穿透
self.setWindowFlags(Frameless | WindowStaysOnTop | Tool)
self.setAttribute(WA_TranslucentBackground)
self.setAttribute(WA_TransparentForMouseInput)   # 不拦截点击
self.setGeometry(整个虚拟桌面的并集)
```

`paintEvent` 关键逻辑：

1. 收集所有录制区矩形（ScreenWindow + CameraWindow 的屏幕坐标 rect）
2. **clip 排除所有录制区内部**：构造 `QPainterPath` = 全屏路径 - 每个录制区 rect → `p.setClipPath(非录制区)`。这样录制区内（含重叠/相邻）永不画雾 ⇒ **重叠部分自动无雾**
3. 在 clip 内，对**每个录制区**沿其四边/四角画向外渐变的白雾：
   - 四边用 `QLinearGradient`（贴边 `alpha≈41` → 外 `0`，范围 ~50px）
   - 四角用 `QRadialGradient` 衔接
   - 多个录制区的雾在非录制区自然叠加；靠近则连成一片，拉远则各自渐淡、中间露出
4. 录制开始/停止 → `show()` / `hide()`，配 0.5s 淡入淡出（`QPropertyAnimation` on `windowOpacity`）

> HTML 预览用 `box-shadow` 向外发散 + 独立底层（z 低于录制区内容）模拟，等价于上面的"clip 排除录制区 + 边缘渐变"。参考 `preview/04_recording_fog_detached.html`（含重叠不雾化、拖拽跟随）。

## 7. 收起态 · 胶囊

录屏区折叠后变为一个 **56×28 圆角胶囊**（`border-radius 14`），磨砂玻璃 `rgba(255,255,255,0.07)` + 边框 `0.13`，内含三个点（中间点稍大），可选扫光动画。点击展开回完整工具。

> 对接现有 `_toggle_collapse`（行 574）：折叠时 resize 成胶囊尺寸，`paintEvent` 折叠分支画胶囊而非现有 pill+文字。

---

## 8. 字幕

字幕开关从顶栏移入**录屏区右上角**，做成磨砂小 chip：

- 默认 `rgba(255,255,255,0.5)` + 一个 CC 样式 icon（圆角小框内两短横）+ "字幕"
- 开启态 `on` 高亮（白 1.0 / 边框 0.3）
- 语言切换（EN/中…，对应现有 `SUBTITLE_LANGS`）可做成 chip 上的次级小标，或点击循环

字幕文本浮层 `SubtitleCard` 样式保持，位置贴录屏区底部。

## 9. 按钮三态规格

见 `preview/02_button_states.html`（可实时悬停/点击）。

| 类型 | 默认 | 悬停 | 按下 |
|------|------|------|------|
| 主（开始录制/保存） | 白 0.90 + 外阴影 | 纯白 + 上移 1px + 阴影加深 | scale 0.96 + 下移 1px + 内阴影 |
| 次（停止/取消/重录） | 深磨砂 0.5 + 边框 0.28 | 背景/边框提亮 + 上移 1px | scale 0.96 + 下移 1px |

原则：主按钮用**位移+阴影**，次按钮用**透明度变化**，不用颜色跳变。
